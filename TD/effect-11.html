炫彩模式
circle 经噪声置换后提取边缘，双路 feedback 分别向内螺旋和向外扩散叠加，生成有机同心圆纹样；再叠加 LFO 驱动色相旋转的橙黄渐变，输出持续变色的迷幻彩色曼陀罗；键盘可切换至彩色噪声模式。
节点截图
过程截图 — transform1/2 的缩放与旋转参数决定螺旋收缩或扩散的速率；lfo1 频率控制色相旋转速度；switch1 的切换由 keyboardin 实时控制。

Logic
Input lfo1（9358 高频）→ math1（映射为 11.55）持续驱动 hsvadj1 色相旋转；keyboardin1 按键切换 switch1 输出模式
Process circle1 + noise1 → displace1（扭曲圆边缘）→ edge1（提取轮廓）→ 双路 feedback：feedback2/transform2 向外扩散，feedback1/transform1 向内收缩，comp 叠合 → ramp1 + hsvadj1（LFO 驱动色相旋转）→ lookup1（查表着色）→ switch1（键盘切换 noise2 备用模式）→ out1
Output 持续变色的迷幻彩色曼陀罗，同心圆纹样同时向内收缩与向外扩散；键盘按下即时切换至彩色噪声模式；out1 输出供后续合成或投影
