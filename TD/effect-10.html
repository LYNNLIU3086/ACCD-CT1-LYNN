[青绿]
[圆环点集经 copy 拉伸成彗星锥形，粒子系统扩散后叠加噪声弯曲，以青绿渐变 point sprite 着色；在青色环境光下渲染出尾迹。]
节点截图 / 过程截图
limit1 的约束范围控制尾迹长度；ramp1 的色相决定粒子整体色调，可从青绿切换至其他颜色；light1 的背景色与 ramp1 协调配色是整体氛围的关键。
Nodes Used
  • [render, bloom, rgbkey, ramp]TOP

Logic
Input [pointgen1：圆环点集作为粒子发射源形状 · ramp1：青绿色渐变 TOP，作为 pointsprite 的颜色纹理输入 · light1：青绿色环境光，决定场景整体色调氛围]
Process

SOP 粒子生成链 pointgen1（圆环点集）→ copy1（沿轴拉伸复制，形成彗星锥形点阵） → null1 → particle1（粒子系统：赋予速度与生命周期，点集开始扩散） → noise1（叠加有机噪声弯曲，破坏直线轨迹） → null2 → transform1（整体空间变换定位） → limit1（约束粒子活动范围，控制尾迹长度）→ geo1

渲染管线 ramp1（青绿渐变）→ pointsprite1（染色每个粒子点为软边椭圆 sprite） geo1 + pointsprite1 + cam1 + light1（青绿环境光） → render1 → bloom1（泛光，让稀薄粒子发光扩散）→ rgbkey1（抠除背景）

Output [青绿色调的稀薄粒子尾迹，在深色背景上若隐若现；bloom 使粒子点发出柔和光晕，整体呈现漂浮的空灵感；rgbkey 抠图后输出透明层供合成]
