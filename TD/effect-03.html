[近邻连线网络]
[以 CHOP 参数总线集中管理运动速度与噪声强度，驱动线段点集在空间中扩散； proximity 节点在距离阈值内的点对之间自动连线，形成有机生长的晶格线网， 与 torus 参考形和 box 阵列共同构成粒子网格感的隧道结构。]

Logic
Input [constant3（motionspeed = 1）→ speed1：运动速度时间积分 · constant4（noisetrans = 0.01）→ speed2：噪声位移速率积分 · constant5（period = 1, amplitude = 1）：噪声周期与振幅]
Process

1-点云生成 pointgen1（线段点集）→ noise1（注入 null2 的4通道参数，受控扩散成颗粒云）→ transform2（整体空间变换）→ limit1（范围约束）→ null1

2-近邻连线 null1 → proximity1：计算点间距离，阈值内自动连线，生成密集线框网格体

3-场景组装 geo1：proximity 线网 + box1/transform1/copy1（方块阵列）+ constant1（torus参考形） geo2：null1 噪声点云 + constant2（椭圆遮罩限制渲染区域）

4-cam1 从正面拍摄 → render1（隧道透视线网）→ rgbkey1（抠除黑底）]

Output [白色近邻连线构成的透视收缩隧道，点云在噪声驱动下持续抖动，线网随之动态重构；经 rgbkey 抠图后输出透明图层供后续合成]
