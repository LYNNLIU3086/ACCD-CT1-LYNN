[4-方块云]
[上层以音频 RMS 振幅经峰谷分析后映射驱动球体的噪声形变与运动； 下层用噪声 TOP 的像素值作为点坐标来源，实例化方块群经强光渲染形成高对比黑白方块丛林。]

trail1 记录振幅历史，max/mini 分别捕捉峰值与谷值，两者之差控制运动的动态范围。

Logic
Input [· audiofilein1：音频文件输入，双通道（chan1/chan2） · audiodevout1：同步播放音频至设备输出 · audiospect1：实时频谱监控（辅助可视化）]
Process

1-球体几何管线（SOP） sphere1 → transform1（音频驱动位置）→ noise1（音频驱动形变强度） → geo1 + constant1（球体渲染）/ geo2 + line1（连线辅助层）

2-噪声方块云管线 noise2（彩色噪声 TOP）→ pointtransform1（像素 RGB 值映射为点 XYZ 坐标） → limit1（约束点范围，输出密集白色点阵） → geo3 + box1（每点实例化小方块） cam1 + light1（强方向光）→ render1（高对比黑白方块丛林）→ out1]

Output [双层输出：音频驱动的球体随节奏形变游走（geo1/geo2）；噪声坐标实例化的方块群在强光下呈现高对比度黑白建筑感画面（out1），两层可后续合成叠加]
