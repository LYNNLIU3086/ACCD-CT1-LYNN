[7-分形的曼陀罗]
[将一条经噪声扰动的线段绕轴旋转成海胆状旋转体，贴上彩虹渐变色后多重复制，形成曼陀罗花纹。两路几何分别以线框与彩色点云渲染，经泛光处理后产生有机发光的放射美感。]
节点截图 / 过程截图
noise1 的 amplitude 控制花瓣轮廓的不规律程度；copy1 的复制数量决定放射对称轴数，值越大越接近满圆曼陀罗。
Nodes Used
  • [render, bloom]TOP
  • [-]CHOP
  • [line, noise, revolve, lookuptex, copy, convert, transform]SOP
  • [—]DAT
  • [ramp]MAT
  • [cam, light, geo]COMP
Logic
Input [ line1：一条直线段作为旋转轮廓的母线 · ramp1：彩虹渐变 TOP，作为 lookuptex 的颜色查找表，将点的位置映射为彩色]
Process [

形态生成 line1 → noise1（扰动轮廓，形成不规则波浪线） → revolve1（绕 Y 轴旋转 360°，生成海胆/梭形旋转体） → lookuptex1 + ramp1（按点位置查表染彩虹色） → copy1（沿圆周多重复制，形成放射对称阵列）

双路分叉渲染 copy1 → convert1 → transform1 → geo1（线框/面模式，白色海胆放射形） copy1 → convert2 → transform2 → geo2（点云/粒子模式，全彩曼陀罗花纹） ]

Output [色放射曼陀罗，线框层与彩色点云层叠合；bloom 让发光点向外晕散，整体呈现珊瑚/海葵在深海中发光的有机美感]
