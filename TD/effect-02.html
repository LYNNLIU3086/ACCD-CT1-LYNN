[2-隧道穿梭]
[以椭圆点集为发射源，经螺旋复制与粒子系统扩散，叠加噪声扰动后渲染成白色粒子构成的旋转隧道。摄像机置于隧道轴心内部向前看，产生穿越宇宙虫洞般的沉浸感。]
节点截图 / 过程截图
背景中密密麻麻的白点正是这条隧道的粒子本身——摄像机就置于隧道内部向前看。
Nodes Used
  • [render, rgbkey]TOP
  • [-]CHOP
  • [pointgen, copy, null, null, particle, noise, limit, transform]SOP
  • [-]DAT
  • [pointsprite]MAT
  • [cam, geo]COMP
Logic
Input [pointgen1 生成椭圆点集作为粒子发射源形状 · transform1 提供可调整的空间变换矩阵]
Process [pointgen1（椭圆点集） → copy1（沿轴向复制堆叠成螺旋线圈） → null1（SOP断点） → particle1（粒子系统：赋予速度、生命周期、扩散） → noise1（对粒子位置叠加噪声扰动，破坏规整感） → null2（合并 transform1 的整体空间变换） → limit1（约束粒子数量与活动范围） → geo1 + pointsprite1（装入几何容器，赋予 sprite 材质） → render1（cam1 从轴心内部正面拍摄，形成同心圆螺旋视角） → rgbkey1（抠除黑色背景，粒子层透明化供后续合成）]
Output [白色粒子 sprite 构成的旋转螺旋隧道；粒子在噪声驱动下持续抖动，隧道边缘向外发散；经 rgbkey 抠图后输出透明粒子层，可与其他图层叠合]
