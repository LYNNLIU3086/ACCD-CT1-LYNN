Logic
Input [noise1：灰度云状噪声，作为整个边缘链的原始素材 keyboardin1（当前值 0）：键盘触发，重置或扰动 feedback1 回路]
Process

Feedback 回路 1（生长叠加） edge5 + keyboardin1 → feedback1（自我叠加，纹理持续生长密集） → level1（控制亮度/残影衰减）→ limit1（范围限制）→ comp1（叠合） → displace1（用 comp1 对自身置换扭曲）→ edge6（第六次边缘，输出极精细白色线网）

Feedback 回路 2（漂移扩散） edge6 → feedback2（线网自我叠加）→ transform1（每帧平移/旋转，驱动漂移） → level2（亮度调整）→ comp2（当前帧 edge6 + 残影叠合） → rgbkey1（抠图）→ level3（最终微调）→ null1（输出）]

Output [高密度白色线网在黑色背景上持续生长漂移，结构层叠细腻如电路板或细胞壁；双路 feedback 分别负责生长密度与空间漂移，null1 输出透明层供后续合成]
