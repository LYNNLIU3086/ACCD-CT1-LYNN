[4-双LFO噪声游走球]
[单个球体受两个反向LFO与噪声联合驱动，在空间中持续有机漂移。渲染后叠加feedback残影拖尾与bloom泛光，产生类似萤火虫或等离子球在黑暗中游走的发光轨迹。]
feedback 残影衰减速率由 level1 的亮度参数控制，值越低残影消散越快。核心是双层 feedback——SOP 层一个（让球持续运动不复位），TOP 层一个（让渲染结果留下光迹残影）——两层反馈配合形成完整的游走发光效果。
Nodes Used
  • [render, feedback, level, over, bloom ]TOP
  • [lfo]CHOP
  • [pointgen, feedback, noise, math, end, select]SOP
  • [-]DAT
  • [constant]MAT
  • [cam, geo]COMP
Logic
Input [lfo1（值 -1）：驱动球体反向运动 · lfo2（值 -2.203）：驱动另一轴向偏移，与 lfo1 频率不同步，产生更复杂的游走路径]
Process

SOP 运动链: pointgen1（生成单点球） → feedback1（SOP反馈：将上一帧位置喂回，形成连续运动而非复位跳变） → noise1（叠加空间噪声扰动，破坏LFO的规律感，lfo1/lfo2 分别注入两轴偏移） → math1（数值缩放/限幅）→ end → select1（输出目标点）

渲染 + 发光回路: select1 → geo1 → render1（cam1 拍摄） render1 → feedback2 → level1 → 回路闭合（残影拖尾，逐帧亮度衰减） render1 + level1 → over1（叠合当前帧与残影） over1 + constant1（椭圆遮罩）→ bloom1（泛光发散）

Output [发光球体在黑色背景上持续游走，身后留有逐渐消散的光迹拖尾；bloom 让球体产生柔和光晕，整体输出可与其他图层叠合]
