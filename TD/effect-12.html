Logic
Input keyboardin1（当前值 0）：键盘交互，触发 feedback 重置或施加瞬间扰动 null2：接收上一级管线的彩色纹理，作为 feedback 的初始帧输入
Process

1-底纹生成（图1） noise1 → edge1（边缘提取）→ blur1（柔化轮廓） noise1 + noise2 → comp1（双噪声叠加）→ comp2（细密黑白纹理） blur1 + noise3（蓝色填充）→ comp3（蓝色裂纹） comp2 → displace1（扭曲 comp3）→ comp4（黄绿色混合叠合） → displace2（二次置换）→ lookup1 + ramp1（青绿渐变着色）→ 输出地貌底纹

2-Feedback 生长回路（图2） null2 → feedback1（彩色纹理自我叠加） feedback1 → slope1（梯度/流向提取）+ noise4（彩色扰动）→ comp5（置换向量图） → displace3（流向驱动扭曲）→ level1（亮度调整）→ comp6（汇合） → hsvadj1（HSV 色相/饱和/亮度精调）→ level2 → edge2（提取边缘描线）→ level3 → comp7（纹理 + 边缘叠合）→ null1（最终输出）

Output 黄绿色调的有机纹理持续蠕动生长，边缘描线随之动态更新；整体呈现熔岩流动、苔藓扩张或生物皮肤蠕动的质感，null1 输出供后续合成或投影使用。
