
Style Guide — Theme Park Maps (suggested palette & icons)
========================================================

Color palette (retro paper aesthetic):
- Paper background: #F6EFE2
- Ink dark: #3B2F2F
- Accent: #B85A2F
- Secondary: #6B5A4A
- Subtle line: #E6DCCF

Typography:
- Headings: Georgia / serif family (for vintage feel)
- Body: Arial or system sans-serif

Visual rules:
- Use bold outlines for major attractions.
- Number attractions and provide a legend in a separate panel.
- Keep wayfinding icons consistent in stroke weight & size.
- Export editable vector (SVG/AI) for future edits.
